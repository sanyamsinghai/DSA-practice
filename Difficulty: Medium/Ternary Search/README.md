<h2><a href="https://www.geeksforgeeks.org/problems/searching-an-element-in-a-sorted-array-ternary-search--141631/1">Ternary Search</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;"><a href="https://www.geeksforgeeks.org/dsa/ternary-search/"><strong>Ternary search</strong></a> is a divide-and-conquer algorithm that divides the search range into three parts and identifies the part that may contain the target element. The process is repeated until the element is found or the search range becomes empty.&nbsp;</span></p>
<p><span style="font-size: 18px;">Given a sorted array arr and an integer x, determine whether x is present in the array using ternary search.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr = [1, 2, 3, 4, 6], x = 6</span><br><span style="font-size: 18px;"><strong>Output: </strong>true</span><br><span style="font-size: 18px;"><strong>Explanation: </strong>The element 6 is present in the array, so the output is true.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr = [1, 3, 4, 5, 6], x = 2</span><br><span style="font-size: 18px;"><strong>Output: </strong>false</span><br><span style="font-size: 18px;"><strong>Explanation: </strong>The element 2 is not present in the array, so the output is false.<br></span></pre>
